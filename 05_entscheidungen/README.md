# Entscheidungsregister

Entscheidungen erhalten fortlaufende ENT-Kennungen. Sie nennen Gegenstand, Quelle, entscheidende Rolle/Person, Datum, Fassung, geprüfte Optionen, tatsächliche Auswahl, Grenzen, Folgen und Wiederaufnahmeauslöser.

| Kennung | Gegenstand | Status |
|---|---|---|
| [ENT-0001](ent_0001_systemauftrag.md) | Eigenständiger Systemauftrag und Aufbau dieses Repositorys | Vom Auftraggeber angenommen; Einrichtungsauftrag erteilt |
| [ENT-0002](ent_0002_arbeitssteuerung_und_journal.md) | Arbeitssteuerung, Prüftiefe, Ergebnisübergabe und verbindliches Journal | Methodenrichtung angenommen; begrenzte Umsetzung beauftragt |

## Entscheidungsgrenzen

Arbeitspriorität, Modellwahl, fachliche Prüfung, Dokumentfreigabe und konkrete Umsetzung sind unterschiedliche Entscheidungen. Ein Repository-Inhaber kann nicht durch einen internen Eintrag die Zustimmung anderer Vertragsparteien oder eine behördliche Entscheidung ersetzen.

Ein neuer Vorschlag wird als Vorschlag geführt, bis die zuständige Person tatsächlich entschieden hat. Spätere Ersetzung enthält Grund und Nachfolgeverweis; frühere Entscheidungen werden nicht so umgeschrieben, als hätten sie immer den neuen Inhalt gehabt.

Die [Entscheidungsvorlage](../08_vorlagen/entscheidung.md) ist eine Arbeitsform. GitHub-Issues koordinieren die Arbeit; sie sind keine zweite, unabhängig gepflegte Quelle verbindlicher Modellentscheidungen.
