# Arbeitsvorlagen

Vorlagen sind Arbeitsformen, keine bereits ausgefüllten Akten oder freigegebenen fachlichen Ergebnisse. „Auszufüllen“ ist nur hier eine zulässige Hilfsmarkierung. Bei einer echten Akte fehlende Information konkret als offen mit Beschaffungsweg kennzeichnen.

| Vorlage | Verwendung |
|---|---|
| [Forschungsakte](forschungsakte.md) | Frage, Hypothese, Varianten, Quellen, Gegenprüfung und Machbarkeit |
| [Modellakte](modellakte.md) | Zusammenhängendes Modell und sein Bearbeitungsstand |
| [Entscheidung](entscheidung.md) | Tatsächliche Auswahl, Befugnis, Grenzen und Folgen |
| [Prozess und Kontrolle](prozess_und_kontrolle.md) | Durchführbare Arbeit und dazugehöriges Kontrollverfahren |
| [Nachweisbewertung](nachweisbewertung.md) | Konkreter Beleg, Aussage, Prüfung und Ergebnisgrenze |
| [Änderungsbewertung](aenderungsbewertung.md) | Herkunft einer Änderung, betroffene Beziehungen und Nachprüfung |

Vorlagen passend zum tatsächlichen Umfang verwenden. Keine Pflicht zu sechs neuen Dateien für eine kleine Frage. Eine gemeinsame Akte ist zulässig, wenn die unterschiedlichen Aussagen, Zustände und Quellen nachvollziehbar bleiben.

Neue reale Akten erhalten die nächste freie Kennung im passenden Register. Vorlage selbst hat keine Aktenidentität. Keine Personen, Prüfer, Zustimmungen oder Datumswerte automatisch vorbelegen.
