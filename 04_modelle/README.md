# Modelle, Profile und Modellpakete

Ein Betriebsprofil beschreibt den Anwendungsrahmen. Eine Modellakte verbindet Nutzen, Struktur, Leistungen, Wirtschaftlichkeit, Verträge, Führung, Betrieb, Anforderungen, Risiken, Kontrollen und Information. Ein Modellpaket ist erst nach begrenzter fachlicher Freigabe zur bezeichneten Verwendung bestimmt.

## Aufbau und Pflege

Modellakten erhalten fortlaufende MA-Kennungen, Profile BP-Kennungen. Ihre Identität bleibt bei redaktioneller Überarbeitung erhalten. Materielle Änderungen verweisen auf eine Bewertung und gegebenenfalls Entscheidung; bedeutende ersetzte Stände bleiben über Historie und erforderlichenfalls Archiv nachvollziehbar.

Die Akte verweist auf maßgebliche Fachbewertungen, Quellen, Entscheidungen und Prüfungen. Eine wesentliche ungeklärte Voraussetzung verhindert eine uneingeschränkte Freigabe. Kleine Ideen benötigen noch keine vollständige Modellakte; dafür genügt die Forschungsarbeit.

Vor einem Modellpaket: Anwendungsbereich, genaue enthaltene Fassungen, notwendige Voraussetzungen, Leistungsgrenzen, offene Punkte, Verwendungserlaubnis, Einführung und Kontrollplan dokumentieren. Ein späterer Paketstand ändert vorhandene Verträge nicht automatisch.
