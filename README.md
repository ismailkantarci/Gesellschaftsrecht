# TAXIPartner – Integriertes Fachsystem

Integriertes Fachsystem zur Erforschung, Entwicklung, Bewertung und Weiterentwicklung der Geschäfts-, Beteiligungs- und Betriebsmodelle von TAXIPartner einschließlich Gesellschaftsverträgen, Unternehmensführung, Compliance und wirksamen Kontrollsystemen.

Dieses Repository erhält einen eigenständigen fachlichen Systemkern. Es ist weder ein Softwarekern noch einem anderen Repository untergeordnet. Die Arbeitssprache ist Deutsch.

Die Ersteinrichtung erfolgt auf ausdrücklichen Auftrag vom 22.09.2026. Fachliche Einzelmodelle, Vertragsklauseln und betriebliche Kontrollen werden dadurch nicht als rechtlich geprüft, eingeführt oder wirksam bestätigt. Vertrauliche Originalunterlagen werden nicht öffentlich eingestellt.
